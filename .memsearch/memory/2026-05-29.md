### 豆包（Doubao）海外情况

**火山引擎国际版**（Volcano Engine International）提供豆包 API，支持新加坡区域：

- **国际版官网**：https://www.volcengine.com（有英文版）
- **API 兼容 OpenAI 格式**，可以直接替换我们的 MiMo 接口
- **支持的模型**：Doubao-pro、Doubao-lite 等
- **有新加坡 region**，延迟很低

### 如果你想换成豆包

只需要改 `.env.local` 里的三个值：

```
NEXT_LLM_URL=https://ark.ap-southeast-1.volces.com/api/v3/chat/completions
NEXT_LLM_API_KEY=你的火山引擎API Key
NEXT_LLM_MODEL=你的模型端点ID
```

### 核心问题：语音 AI Agent 的门槛太高

现在市面上的 AI（ChatGPT、豆包、Kimi）都是**打字聊天**。但现实中很多场景**打字不方便**：

- 开车时想问路
- 做饭时想查菜谱
- 老人/小孩不会打字
- 多任务时想语音交互

**想做一个语音 AI 产品？** 目前的痛点是：

| 问题 | 传统做法 | VoxAgent |
|------|---------|----------|
| 实时语音传输 | 自己搭 WebRTC，很难 | Agora 一行代码搞定 |
| 语音转文字 | 自己接 STT，延迟高 | Agora 云端处理，亚秒级 |
| AI 推理 | 自己训模型或接 API | 插上 key 就能用 |
| 文字转语音 | 自己调 TTS，音质差 | Agora 内置高质量 TTS |
