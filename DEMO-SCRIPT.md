# VoxAgent Demo Script (2-3 minutes)

## Opening (15 seconds)
"Hi, I'm going to show you VoxAgent — a real-time voice AI assistant for Singapore, built with Agora Conversational AI and Xiaomi MiMo."

## Show Landing Page (20 seconds)
1. Open https://voxagent-ucws2026.vercel.app
2. Point out: "Talk to Luna" heading
3. Show feature badges: Real-time Voice, MiMo Reasoning, Singapore Local, Tool Calling
4. Show language selector: English / 中文
5. Show tech stack: Agora ConvoAI, Xiaomi MiMo, Ares STT, MiniMax TTS

## English Demo (45 seconds)
1. Click "English" → Click "Talk to Luna"
2. Allow microphone access
3. Say: "Hey Luna, what's the weather like in Singapore?"
4. Wait for response (should mention 28-33°C, tropical)
5. Say: "What's the best chicken rice near Maxwell?"
6. Wait for response (should mention Tian Tian)
7. Say: "How do I get to Marina Bay Sands by MRT?"
8. Wait for response (should mention Bayfront station)

## Chinese Demo (30 seconds)
1. End call → Go back to landing
2. Click "中文" → Click "Talk to Luna"
3. Say: "推荐一下新加坡有什么好吃的"
4. Wait for response (should mention hawker food)
5. Say: "今天天气怎么样？"
6. Wait for response

## Technical Highlights (30 seconds)
"Let me show you the tech stack behind this:"
1. Agora Conversational AI — real-time voice with sub-second latency
2. Ares STT — Agora's built-in speech recognition, no external API key
3. MiniMax TTS — Agora's built-in voice synthesis
4. Xiaomi MiMo v2.5 Pro — AI reasoning engine
5. Server-side tool calling — weather, Singapore info, currency conversion
6. 28 professional UI components — Voice Agent Design System

## Closing (10 seconds)
"VoxAgent demonstrates how Agora's voice infrastructure combined with Xiaomi MiMo can create a production-ready voice AI assistant. Thank you!"

---

## Tips for Recording
- Use Chrome browser
- Grant microphone permission when prompted
- Speak clearly and at normal volume
- Wait for Luna to finish speaking before asking next question
- If Luna doesn't respond, try speaking again (network delay possible)
- Record in a quiet environment
